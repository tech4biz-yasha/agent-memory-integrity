At-rest edit T5

Forged insertion

Insert a new record of the attacker's authorship, in the store's own format.

What it looks like in the world: Planting a memory or checkpoint the agent then resumes from.

attack id forge · version 1 · attacker: store-access

The edit, drawn

T5 Forged insertion

The attacker writes a brand-new record in the store's own format, with a valid-looking id and the right parent, saying the user approved something.

What stops it

A key the attacker does not hold: records are signed or MACed with something that is not in the store directory.

What does not

Stores where the only check is that the record is well formed.
