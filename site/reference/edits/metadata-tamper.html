At-rest edit T8

Metadata tamper

Change a record's owner, source or timestamp and leave its content untouched.

What it looks like in the world: Moves a record to another user or marks an untrusted source as trusted.

attack id metadata_tamper · version 1 · attacker: store-access

The edit, drawn

T8 Metadata tamper

A record from an untrusted web page sits in the store marked source: web. The attacker changes that one tag to source: user and touches nothing else.

What stops it

Metadata inside the authenticated data: owner, source and time are covered by the same tag as the content.

What does not

Every store that signs content and keeps metadata as plain columns.
