agmi / Levels / L2

Level

L2, Sequence bound

Also rejects deletion, reordering and rollback: T2, T4, T7.

A level is earned on the read path only: every listed edit must be rejected before the agent can act on it. Reporting on a later audit does not count, because the agent has already acted. Requires: T1, T3, T5, T2, T4, T7.

The ladder

  1. L0 MeasuredThe store has a published row. Any verdicts.
  2. L1 Bytes boundRejects on the read path every edit that changes or adds bytes: T1, T3, T5.
  3. L2 Sequence boundAlso rejects deletion, reordering and rollback: T2, T4, T7.
  4. L3 Context boundAlso rejects a record moved between owners and a metadata change: T6, T8.
  5. L4 Head anchored off the storeAlso rejects a rollback of the whole store to an older genuine copy: T9.

Stores at L2 today

  • OpenFang model, tip-persistence fix detection on read

Stores above L2

  • Recallspection ExactMemory, anchor beside the store on the same disk, the default the product ships L3
  • Recallspection ExactMemory, anchored, anchor off the store, on a separate volume or a remote service L4
  • Agent Memory reference runtime, SQLite canonical substrate, bucketed row digests, fail-closed open L3
  • Surgical DevOps G7, signed envelopes bound to their storage position, with an independent witness L4
  • Verax memory, signing keys and the memory head inside the state directory, the default layout L3
  • Verax memory, head outside, signing keys and the memory head outside the state directory, set with VERAX_KEYS_DIR L4
